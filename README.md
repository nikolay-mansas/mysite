# MySite
[![MySite CI/CD](https://github.com/nikolay-mansas/mysite/actions/workflows/ci_cd.yml/badge.svg)](https://github.com/nikolay-mansas/mysite/actions/workflows/ci_cd.yml)

A small personal portfolio website built with SvelteKit.

## ✨ What’s inside

- Clean one-page portfolio layout
- Bilingual content with inlang/paraglide
- Responsive design
- Project and experience sections
- Simple contact/social links

## 🛠️ Tech stack

- SvelteKit
- TypeScript
- Tailwind CSS
- Vite
- Paraglide for translations

## ▶️ Run locally

Install dependencies:

```bash
npm install
```

Start the dev server:

```bash
npm run dev
```

Then open http://localhost:5173 in your browser.

## 🧱 Build

```bash
npm run build
```

## 📁 Project structure

- src/routes — pages and layout
- src/lib/components — UI components
- src/lib/config.ts — main site content and links
- messages/ — translations

## 💡 Notes

The site content is mostly driven by configuration files, so it is easy to update with your own projects, links, and biography.
